\subsection{Analyse des messages du solveur}
\label{sec:Analyse des messages du solveur}

\begin{frame}[c]{Analyse des messages du solveur}
    \begin{itemize}
        \item Pour chaque warning laissé dans la solution finale, et en suivant des sources fiables (pas de GPT, mais la doc du logiciel)
        \begin{itemize}
            \item Description
            \item Cause
            \item Impact
            \item Décision
        \end{itemize}
        \item Pour faciliter la recherche, utiliser plutôt le logiciel en anglais, les traductions laissant souvent à désirer
    \end{itemize}
\end{frame}
